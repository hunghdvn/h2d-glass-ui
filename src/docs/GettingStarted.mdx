# Getting started

fl-glass-ui is a glassmorphism component library for React 18.3+ and 19. It ships plain CSS and
works in React Server Components.

## Install

```bash
pnpm add fl-glass-ui
```

## Load the styles once

```tsx
import 'fl-glass-ui/styles.css';
```

All library CSS lives in the `flg` cascade layer, so any CSS you write outside a layer overrides it
without `!important`.

## Use a component

```tsx
import { Button, Card, CardContent, CardFooter, CardHeader, CardTitle } from 'fl-glass-ui';

export function Upgrade() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Upgrade to Pro</CardTitle>
      </CardHeader>
      <CardContent>Unlimited sync and priority support.</CardContent>
      <CardFooter>
        <Button variant="ghost">Not now</Button>
        <Button>Upgrade</Button>
      </CardFooter>
    </Card>
  );
}
```

Phase 1 components: Surface, Card, Button, IconButton, Badge, Avatar, Divider, Spinner, Field,
Input, Textarea, Checkbox, RadioGroup and Switch.

## Build a form

Wrap each control in a `Field` for its label, description and error. Every control is a native
form element underneath, so `FormData`, the browser's validation and form libraries work as usual.

```tsx
import { Field, Input } from 'fl-glass-ui';

<Field label="Email" description="We only use it to send sign-in links." error={errors.email}>
  <Input name="email" type="email" autoComplete="email" />
</Field>;
```

## Pick a theme

Without a `data-flg-theme` attribute the library follows the operating system's light or dark
preference. Set the attribute to force a theme, on `<html>` or on any subtree:

```html
<html data-flg-theme="dark"></html>
```

With next-themes, set `attribute="data-flg-theme"`.
