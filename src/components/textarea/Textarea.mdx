## In a Field

Inside a `Field` with an `error` the textarea is invalid. Pass `invalid` to mark it yourself. The
red border stays while the textarea has focus, so the error remains visible while the user fixes
it. Focus is then shown by the focus ring alone, which is faint in the default theme (see the
Accessibility page, row 2); the `prefers-contrast: more` mode adds a solid outline.

## Accessibility

- Renders a native `<textarea>`; the ref and every prop go to it.
- The user can resize it vertically. Set `rows` for its starting height.
- Give it a name with a `Field` label or `aria-label`.

## Do and don't

- Do say how long the text should be in the description when there is a limit.
- Don't use it for a single line of text; use `Input`.
